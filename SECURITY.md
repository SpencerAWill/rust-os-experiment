# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/SpencerAWill/rust-os-experiment/security/advisories/new), not in public issues. You will get a reply within a week.

## Scope

This is an experiment that does not boot yet and is not meant to run anything you depend on. In scope: the repository's own tooling (`xtask`, the Claude Code hooks and skills, the GitHub workflows and settings), and, once it exists, kernel code whose isolation does not hold as documented.
